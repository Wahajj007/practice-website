# Redline — Blood Donation Portal

Bare-bones static website skeleton made with HTML, CSS and JavaScript.

Pages:
- `index.html` — Landing Page
- `products.html` — Product Display / Donation Information
- `cart.html` — Shopping Cart / Saved Resources
- `payment.html` — Payment / Registration form

## Vercel
1. Put this folder in a GitHub repository.
2. Go to Vercel and import the repository.
3. Framework preset: **Other**
4. Build command: leave empty.
5. Output directory: leave empty.
6. Deploy.

No backend or database is required for this demo.
